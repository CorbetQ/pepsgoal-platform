# Prototype web PepsGoal

`pepsgoal.html` est le prototype complet d'origine : un seul fichier, aucune installation, toutes les données dans le navigateur.
Il sert de **référence fonctionnelle et visuelle** pour porter les écrans dans `apps/app` (voir docs/ARCHITECTURE.md).

Il fonctionne aussi seul : mode sans compte, hors ligne, modération locale, import / export .zip.

Pour une démonstration publique sans données d'exemple, passer `const DEMO_MODE = true;` à `false` dans le fichier,
ou utiliser Modération › Maintenances › « Supprimer les données de démo » avec le compte admin.
